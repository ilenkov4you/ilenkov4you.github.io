# Dmitrii Ilenkov — personal website

One static page, no build step. Hosted on GitHub Pages.

- `index.html` — the page (styles and structured data inline)
- `portrait.jpg`, `og-image.jpg`, `favicon.ico`, `icon-192.png`, `apple-touch-icon.png` — images
- `robots.txt`, `sitemap.xml`, `llms.txt` — for search engines and AI assistants
- `CLAUDE.md` — working rules for Claude Code

To change the site, edit `index.html` and push to `main`.
